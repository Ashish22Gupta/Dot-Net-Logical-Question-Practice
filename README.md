## About

This repository contains daily C# practice problems covering:

- **Pattern Printing** – Nested loops, spacing, matrices
- **Array Manipulation** – Sorting, searching, swapping
- **Number Logic** – Prime, Palindrome, Strong, Neon, Armstrong, etc.
- **Matrix Problems** – Spiral traversal, number grids

Each file is self-contained with a `Main` method and expected output documented in comments.
